# C.4 Technical and organisational security measures

Meet a recognised security standard: ISO 27001 or SOC 2 Type II.

| Control # | Control                                                                                              | Source                        | Primary owner | Supporting functions |
| --------- | ---------------------------------------------------------------------------------------------------- | ----------------------------- | ------------- | -------------------- |
| C.4.i     | Document the security measures protecting customer data, and be ready to share them.                 | Enterprise vendor requirement | Security      | Engineering          |
| C.4.ii    | Have a process to detect, record, investigate and report personal data breaches without undue delay. | Enterprise vendor requirement | Security      | Legal & Privacy      |
| C.4.iii   | Have controls for secure storage, encryption, access management and sharing data with third parties. | Enterprise vendor requirement | Security      | Engineering          |
